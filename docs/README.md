# 《成神七日》三十頁漫畫版

此目錄是獨立新版；根目錄的 `成神七日.md` 與 `成神七日-漫畫/` 八張原圖保持原樣。`storyboard.json` 與 `storyboard.en.json` 定義三十個不同場景及繁體中文、英文台詞。每張新圖依序存為 `pages/01.png` 至 `pages/30.png`，不在圖片內生成文字；閱讀器依 `layout.json` 與 `layout.en.json` 在畫面上排出對話框。頁面右上角可切換語言，也可展開文字稿。

## 原作與人物

- 主題：威爾上傳意識後，思考速度逐日暴增；他能修復世界，卻越來越無法與妻子艾芙琳共享時間。結局是二十四小時的肉身重建讓他經歷數百億年的孤獨，重逢時人性已耗盡。
- 威爾：四十歲左右的白人男性，短而略亂的深棕髮、瘦長臉、淡鬍渣。上傳前穿深色實驗室襯衫；數位狀態是同一張臉的半透明電藍色網格；重生的肉身仍是同一張臉，灰色襯衫，目光空洞。
- 艾芙琳：三十多至四十歲的白人女性，肩長、微捲的赤褐髮，綠眼。實驗室穿深藍外套與白襯衫；地下室穿深色實用外套。人物始終是同一人。
- RIFT 女頭目：東亞裔女性，黑色不對稱短髮，一側剃短，黑色戰術服。只出現在突襲段落。
- 首席科學家：深髮、戴眼鏡、灰白實驗袍。與威爾的臉、服裝和剪影明顯不同。
- 視覺語言：近黑背景、電藍意識與網路、銀色奈米機械、紅色病毒、暖琥珀色的人類記憶、紫綠極光。每頁以不同鏡位及動作推進，不重複原圖。

## 改編重點

原有八張縱向漫畫構圖完整，但大多數頁面幾乎沒有對話，人物情緒與時間跳躍需要更明確的過渡。三十頁版把「一句話要等半年」「子彈飛行十天」「一毫秒攻防」「二十四小時等於億萬年」各自留出畫面，並增加艾芙琳的視角與威爾在發射前的選擇。第 21 頁艾芙琳的留言是改編新增，服務於原作最後的自由意志主題。

量子糾纏和電磁防護是原作的科幻設定；畫面應呈現敘事結果，不把它們當作現實科學解說。避免在圖上生成公式、長文字或微小儀表字。必要資訊由閱讀器文字層表達。

## 圖像與發布檢查

每頁一張真正不同的直向漫畫圖，建議至少 1024 × 1536，畫面內無文字、無氣泡、無浮水印。以對應章節的原圖為角色與風格參考。保留適當呼吸空間；避免過多小格導致手機難以辨讀。

執行 `python3 docs/qa_pages.py`，核對三十張圖片的存在、尺寸、縱向比例、檔案重複、雙語台詞及逐頁文字框審核狀態。製作期間可加上 `--partial` 只檢查已完成的圖片。頁面另經人工逐頁檢查人物一致性、畫面與故事對應、中英文斷句、手機直向顯示及原尺寸開啟。GitHub Pages 使用 `main` 分支的 `/docs` 目錄。
